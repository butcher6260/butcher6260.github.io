🚀 Getting Started

Follow these steps to install and run the software on your computer.

  1. Visit the Download Page: Go to the official release page to find the latest version of the app.
  2. Select Your File: Look for the file that ends in .dmg for macOS, as Meridian is built using Apple's development tools.
  3. Download: Click the file name to start the download to your computer.
  4. Install: Open the downloaded file from your browser or your Downloads folder. Drag the Meridian icon into your Applications folder.
  5. Run: Open your Applications folder and double-click the Meridian icon to start the program.
